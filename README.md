# Media Downloader — versi video, gambar, dan audio

Website statis bertema gelap yang bisa diterbitkan melalui GitHub Pages.

## Dukungan file langsung
- Video: MP4, WebM, MOV, M4V, OGV
- Gambar: JPG, JPEG, PNG, GIF, WebP, AVIF, BMP, SVG
- Audio/suara: MP3, M4A, WAV, OGG/OGA, AAC, FLAC, Opus, AIFF, WMA

Website mengenali ekstensi file pada URL dan menawarkan opsi membuka atau mencoba mengunduhnya. Ini bukan jaminan bahwa server sumber akan mengizinkan pengunduhan; beberapa URL membutuhkan token, cookie, atau header khusus.

## Media sosial
Instagram, TikTok, Facebook, X/Twitter, dan YouTube dikenali sebagai tautan sumber. Pada versi ini tombol membuka postingan asli. Website tidak mengunduh otomatis audio/video dari postingan sosial karena GitHub Pages hanya menyajikan file statis, dan akses media harus mengikuti API, izin, hak cipta, serta ketentuan platform yang berlaku.

## Publikasikan
1. Ekstrak ZIP.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository GitHub.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Buka URL Pages yang ditampilkan GitHub setelah deployment selesai.

Dokumentasi resmi: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
